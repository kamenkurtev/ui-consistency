# Joining a process

**Read when:** a process running this work has a spec or a plan, or a plan or
pattern file written before this work began is at hand.

- **Add to the spec or plan of the process running this work**: findings into
  its document, questions into its questions. Never a second dialogue.
- **A plan or pattern file written before this work began** is not a process to
  join, even when a person attached it: read it as `ui-consistency:decisions`,
  *A plan written before this work began*, says.
