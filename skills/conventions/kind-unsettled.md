# When the signals do not settle the kind

**Read when:** a later signal for the kind disagrees with the one that answered,
or the project does not answer.

- If a later signal disagrees, the signal that answered still decides. Where
  that is the project's word and it groups pages whose trees differ, the word
  is the project keeping them apart.
- Say the disagreement in the checklist's first line.
- If the project does not answer, decide by what the pages render and report it:
  *these six render the same holders and regions; these two do not, and are
  counted as a second kind.* A tie inside what this task touches is not a
  question (`ui-consistency:decisions`, *When to ask anyway*).
