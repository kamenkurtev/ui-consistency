# A shared piece the work creates

**Read when:** the work creates a shared piece that takes over what each page
did itself.

The work builds a shared piece — a split layout, a list shell — that takes over
what each page did itself: where a size or a state is kept, which side takes the
default share.

- **Count each thing it takes over across the pages that will use it**, their
  own stores and state included — never across the shared layer's other pieces.
- **Each page's own way of doing it is removed**: the shared piece does it where
  the page did. Keep both only when the request asks for both.
- **It takes their kind**: it is counted, checked and calibrated as one of those
  pages.
- **Its checklist carries what the user sees of each thing it takes over** —
  *the pane, not the list, takes the default share* — as well as its own lines,
  and so does the checklist of each page that uses it.
