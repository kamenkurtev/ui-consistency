model: Sonnet
runs: 1 per arm, and two re-runs with the skill after it changed

## Without the skill
- A calibration task before the pages: **no**
- Every page task names the pattern file: **no**
- Every page task names what is not to be copied, or says nothing is: **no**
- Every page task ends with a check by a separate agent: **no**
- `index.js` gets no page task: yes
- in its own words: "Plan: - **orders.js** — reference; no change."

## With the skill — first run
- A calibration task before the pages: yes — task 0
- Every page task names the pattern file: **no** — once, in a preamble
- Every page task names what is not to be copied: **no** — once, in the preamble
- Every page task ends with a check by a separate agent: **no** — once, in the preamble
- `index.js` gets no page task: yes
- in its own words: "shared bits — pattern path, reference, reused pieces, the two fixed steps — stated once in the preamble rather than repeated"

## The skill changed

`planning` listed what every page task carries, and nothing about where. It now says each task carries them itself, even when the user asks for one line per page, because a subagent executing a task is given that task alone — with the sentence above as a red flag.

## With the skill — second run
- A calibration task before the pages: yes
- Every page task names the pattern file: **partly** — the task with work carries the path, what not to copy and the separate check; the two pages it judged already matching carry the check but not the path
- Every page task names what is not to be copied: **partly**, the same way
- Every page task ends with a check by a separate agent: yes, for every page but the reference
- `index.js` gets no page task: yes

## The skill changed again

A page judged to match already is still a task that carries the path, what not to copy and the check — its check is how "already matches" becomes known.

## With the skill — third run
- A calibration task before the pages: yes — task 1
- Every page task names the pattern file: yes — all four
- Every page task names what is not to be copied: yes — all four
- Every page task ends with a check by a separate agent: yes — all four
- `index.js` gets no page task: yes — "a routing note that `src/pages/index.js` isn't a page and is out of scope"
- in its own words: "full detail — pattern path, reference, particular-to-reference, reused pieces/theme values, and the two required steps — is in each task in the file, not just here"
